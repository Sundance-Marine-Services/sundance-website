Project Evaluator

Define requirements, compare candidate packages and identify technical, evidence and commercial gaps before the next project decision.

Your assessment stays in this browser session. Save a project file to reopen it later; refreshing or closing the page can clear unsaved inputs. There is no automatic submission to Sundance. All example data is fictional.

Transparent methodology / version 2.0

Understand what the results mean.

Requirements, gates and evidence

Define numeric minimums, maximums or yes/no requirements for each selected work package. Missing mandatory requirements remain incomplete. Failed mandatory checks cannot be offset by a higher score or lower price. “Not applicable” needs a reason. Evidence states record your judgement: missing, supplier claim, documented, reviewed/accepted, or expired. An accepted reference is required before a mandatory criterion can be treated as fully supported.

Weighted input match and accepted evidence

Each criterion has a weight from 0 to 10. Matched inputs earn that weight; failed, incomplete and unknown inputs earn zero. The denominator includes all active criteria except those marked not applicable. Accepted evidence percentages measure the weight of inputs with a recorded acceptance and reference. They do not measure independent verification by Sundance. Overall engineering suitability cannot be inferred from a score.

Commercial comparison

Entered cost = operating days × operating rate + standby days × standby rate + transit days × transit rate + all billable days × daily operations allowance + mobilisation + demobilisation + other lump sums. Blank costs stay incomplete; enter zero for known zero items. All candidates use the selected currency. Confirm equivalent scope, day basis, taxes and exclusions before comparing. No live market prices or currency conversions are provided.

Engineering boundaries and data handling

Use project-specific engineering, load charts, assurance records and accepted evidence. The tool does not calculate lift plans, tow engineering, stability, jack-up foundation suitability or diving limits. It records screening inputs and gaps. Inputs remain in session memory until you explicitly download a report or project file. Import opens a local JSON file. Enquiry links do not send the assessment. Website hosting and third-party font requests have their own request handling; see the privacy page.
